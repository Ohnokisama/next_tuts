To learn about handling errors, check out error.tsx in the [reviewId] folder - reset function is used to reload the component affected by the error without reloading the entire project

The placement of error.tsx in nested layouts plays a crucial role in determining the scope of error handling, allowing for more precise control over which parts of the UI are affected when errors occur

For errors in layout files, place the error.tsx file in a higher folder hierarchy than the layout.tsx file e.g. move the error.tsx file in the [reviewId] folder to the products folder for it to affect the layout.tsx in the [productId] folder

To learn parallel routing, check out the complex folder - Parallel routing uses slots to show different UI content together at a time, without changing the URL; it is useful for complex dashboards in showing different info that might have different loading times, errors etc. This allows the user to check other parts of a page if a part is still loading or has errors
